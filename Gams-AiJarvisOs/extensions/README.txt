# Gams Ai Jarvis Os (v1.0.0)
# Drop unpacked Chrome extensions here to auto-load them on browser start.
#
# HOW TO INSTALL AN EXTENSION:
# 1. In Chrome, go to chrome://extensions
# 2. Enable Developer Mode (top right)
# 3. Click "Pack extension" OR find the extension folder in:
#      C:\Users\<YOU>\AppData\Local\Google\Chrome\User Data\Default\Extensions\<ID>\
# 4. Copy the unpacked extension folder here, e.g.:
#      extensions/
#        capsolver/
#          manifest.json   <-- must exist
#          ...
#
# POPULAR EXTENSIONS TO USE:
#   - CapSolver     → https://www.capsolver.com/blog/Extension/install-capsolver-extension
#   - 2Captcha Auto → https://2captcha.com/2captcha-auto (browser extension version)
#   - uBlock Origin → https://github.com/gorhill/uBlock/releases → download .zip of last release
#
# NOTE: Extensions are loaded automatically — no code changes needed.
#       Jarvis detects any folder with manifest.json and loads it.
